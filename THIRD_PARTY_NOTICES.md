# Reference attribution

Svara's decision-and-browser architecture is inspired by [moritzkremb/jev-voice-browser](https://github.com/moritzkremb/jev-voice-browser): typed Jev questions, a constrained action executor, bounded page snapshots, and explicit confirmation. The reference repository was consulted during implementation. Its notice is retained here.
